Modifications: Claude-specific entry points are replaced with OpenCode v2 native skills (entered by `@skill` mention or keyword; no slash commands), question, subagent, read/write/edit/patch, permission rules, and plugin tools. The product is limited to deep-interview, ralplan, ultragoal, the eight owned roles, current-session state tools, native session document paths, and a finite read-only AST/LSP surface. OMC's company-context call is removed. State is a current trusted-session JSON snapshot using a same-process target queue and temporary-file rename; it is not the OMC SQLite/IPC/liveness/recovery design. Native document Write is outside that queue and uses same-slug overwrite without a receipt, suffix, index, or transaction guarantee. The ported ralplan lane removes the Analyst role, the Codex provider passes, `omc ask`, the `.omc/` paths, `/oh-my-claudecode:start-work`, the Claude model pins, the stop-hook cancel-signal semantics, and the active-subagent and stale-timestamp bypasses. It substitutes `Task` and `AskUserQuestion` with the native `subagent` and `question` tools, the Stop hook with a continuation on `session.execution.succeeded`, `/oh-my-claudecode:cancel` with `state_clear(mode="ralplan")`, and takes each role's model and optional `variant` from the plugin's own settings.

OMX rhythm, mandatory pressure, four-closure enforcement, and downstream workflow functionality are not retained as runtime product behavior. OMX attribution remains for actual retained derived historical analysis/material; removal of functionality does not erase provenance. OMO boulder/registry, fallback policy, and full storage/lock/receipt systems are not included. The GJC (gajae-code) session-directory pattern is referenced for path layout, the `_session-` prefix, and the fail-closed rule for ambiguous session-directory matches only; GJC's handoff-verb model (a caller lowered to `current_phase:"handoff"` while raising the callee's state, and a skill-tool chain guard that rejects a workflow-to-workflow skill switch outside that path) is likewise referenced only, for the `ultragoal`/`ralplan` `handoff`/`resume` design; GJC code is not copied wholesale in either case.

The former SQLite host-load investigation is historical evidence only. The current package claims no SQLite dependency, SQL backend, or SQLite probe. LSP servers are not downloaded automatically; their internal filesystem reads are not represented as a per-file sandbox. The document specialist's documented `chub` protocol is read-only and does not narrow the `shell` permission; the restriction is prompt-level.
