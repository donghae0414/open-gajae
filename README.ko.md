# open-gajae

**oh-my-claudecode(omc)**, **oh-my-codex(omx)**, **oh-my-openagent(omo)**에서 영감을 받아 [OpenCode](https://github.com/anomalyco/opencode) 플러그인을 만들어 보는 학습 프로젝트입니다.

일시적으로 OpenCode만 사용할 수밖에 없는 상황에서, 이 프로젝트들을 공부하며 직접 OpenCode 플러그인을 구현해 보고자 시작했습니다.

omc와 omx의 기능을 분석하여 유용한 아이디어를 OpenCode에 이식하고, 이미 동작하는 OpenCode 플러그인이자 에이전트 하네스인 omo에서 구현 방식을 배우는 것이 목표입니다.

## 참고 프로젝트

- **omc — oh-my-claudecode:** Claude Code 플러그인.
- **omx — oh-my-codex:** Codex 플러그인.
- **omo — oh-my-openagent:** OpenCode 하네스이자 플러그인 구현 참고 자료.

현재는 초기 설정 단계입니다. 로컬 참고 저장소와 에이전트 상태 디렉터리는 버전 관리에서 제외합니다.
