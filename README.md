# open-gajae

A learning project to build a plugin for [OpenCode](https://github.com/anomalyco/opencode), inspired by **oh-my-claudecode (omc)**, **oh-my-codex (omx)**, and **oh-my-openagent (omo)**.

Temporarily limited to using OpenCode, I started open-gajae to study these projects and try building an OpenCode plugin of my own.

The goal is to analyze features from omc and omx, adapt useful ideas to OpenCode, and learn from omo as a working example of an OpenCode plugin and agent harness.

## References

- **omc — oh-my-claudecode:** a Claude Code plugin.
- **omx — oh-my-codex:** a Codex plugin.
- **omo — oh-my-openagent:** an OpenCode harness and plugin implementation reference.

The project is in its initial setup stage. Local reference repositories and agent state directories are excluded from version control.
